## 引言

2026年6月29日，最高人民法院发布《关于审理建设工程施工合同纠纷案件适用法律问题的解释（二）》（法释〔2026〕12号，以下简称《建工解释二》），自2026年6月30日起施行。[1] 这是自2020年12月《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》（法释〔2020〕25号，以下简称《建工解释一》）施行以来，建设工程施工合同纠纷审判规则的又一次系统性更新。

《建工解释二》共二十三条，篇幅虽不长，却在多个核心议题上推翻了沿用多年的裁判规则。其中，影响最为深远的当属对"实际施工人"制度的根本性重塑——不仅废止了该概念本身，更彻底关闭了转包和违法分包情形下实际施工人突破合同相对性直接向发包人主张权利的通道。除此之外，合同效力认定规则的"精准化"、挂靠治理的"全链条封堵"、结算规则的细化以及建设工程价款优先受偿权的体系化，共同构成了本次司法解释的核心制度变革。

本文从实务视角出发，以新旧规则对比为主线，着重分析实际施工人制度的变革逻辑及其对诉讼实务的影响，并就其他重点制度变化进行逐项评析，旨在为建设工程领域的法律实务工作者提供一份较为系统的参考。

## 一、规则变化总览：七大板块的系统重构

根据最高人民法院民一庭庭长陈宜芳在答记者问中的权威解读，《建工解释二》的二十三个条文（除第二十三条施行时间外）围绕七个方面展开。[2] 以下表格呈现《建工解释二》与《建工解释一》对应规则的变化关系：

| 制度板块 | 《建工解释一》核心条文 | 《建工解释二》对应条文 | 变化性质 |
|:---|:---|:---|:---|
| **招投标与合同效力** | 第1条第1款第3项：应招未招→合同无效 | 第1条：起诉时不再属于必招项目→不认定无效 | 限缩无效范围 |
| **"黑白合同"规则** | 第2条第1款：以中标合同确定权利义务 | 第2条：新增"先定后招"情形→中标合同无效 | 新增无效情形 |
| **挂靠规制** | 第1条第1款第2项：挂靠合同无效 | 第3-5条：挂靠协议无效+管理费不支持+发包人分层责任+表见代理 | 系统性强化 |
| **实际施工人制度** | **第43条：可突破合同相对性直接诉发包人** | **第6条：禁止突破合同相对性→第7条代位权替代** | **根本性颠覆** |
| **农民工工资保护** | 间接保护（通过实际施工人制度） | 第8条：直接适用《保障农民工工资支付条例》诉权 | 路径转换 |
| **固定价合同结算** | 未专门规定 | 第9条（价格调整限制）+第10条（比例法结算） | 新增规则 |
| **合同无效后处理** | 第6条、第24条 散见规则 | 第11条（参照范围细化）+第12条（折价协议效力）+第14条（质保金） | 系统细化 |
| **审计/财评条款** | 未专门规定 | 第13条：限制审计条款滥用 | 新增规则 |
| **优先受偿权** | 第35-42条 | 第17-21条：范围、折价条件、转让、代位、起算 | 体系化完善 |
| **违法行为移送** | 未专门规定 | 第22条：通报移送行政主管部门/侦查机关 | 新增机制 |

## 二、实际施工人制度的根本性重塑

### （一）"实际施工人"概念的废止

《建工解释二》最重大的变化，是不再使用"实际施工人"这一沿用二十余年的概念，转而以"借用资质的单位或者个人""接受转包的单位或者个人""接受违法分包的单位或者个人"等精确法律表述替代。[3]

这一变化绝非文字游戏，而是反映出最高法对建工领域违法主体司法政策的根本性调整。回溯制度的起源，"实际施工人"概念由2004年《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》（法释〔2004〕14号，已废止）首次创设，其制度初衷在于为农民工工资提供兜底保护。2019年12月，《保障农民工工资支付条例》（国务院令第724号）公布施行，该条例第四章从建设单位、施工总承包单位和分包单位的责任配置出发，构建了保障农民工工资支付的专项法律制度。[4] 在条例已经为农民工工资提供了直接、明确的制度保障之后，继续依赖"实际施工人"制度来实现农民工保护的功能性基础已经不复存在。

更重要的是，正如最高法院指出的，该制度在实践中衍生出了逆向激励效应——"实务中，已出现合法接受分包的施工人甚至主动要求认定分包合同无效的情形，其目的是为自己'创设'实际施工人身份，进而能够直接向发包人主张权利"。[5]

### （二）新旧规则核心对比

以下表格集中呈现《建工解释二》与《建工解释一》在相关主体权利配置上的根本性差异：

| 对比维度 | 《建工解释一》 | 《建工解释二》 | 变化评析 |
|:---|:---|:---|:---|
| **核心概念** | "实际施工人"（统一称谓） | 区分三类主体分别表述 | 精细化区分，废除统一概念 |
| **转包/违法分包人→发包人 直接诉权** | **第43条：可以**突破合同相对性，直接诉发包人；法院追加转包人/违法分包人为第三人；发包人在欠付工程款范围内承担责任 | **第6条：不予支持** | **根本性颠覆——"王牌条款"废止** |
| **挂靠人→发包人 直接诉权** | 第1条第1款第2项+司法实践：部分法院支持，部分不支持 | 第4条：以发包人是否知情为分水岭；不知情则不支持，知情则追加被挂靠人后判决发包人承担责任 | 标准化+分层化 |
| **代位权主体范围** | 第44条：仅限实际施工人 | **第7条：扩大至借用资质方+转包接受方+违法分包接受方** | 代位权主体扩大 |
| **农民工工资** | 实际施工人制度间接保护 | 第8条：直接援引《保障农民工工资支付条例》诉权 | 路径转换，保护更直接 |

### （三）第6条与第43条的核心差异——最关键的实务变化

```
表：实际施工人直接诉权删除前后对比

┌─────────────────────────────────────────────────────────────────┐
│ 《建工解释一》第43条（不再适用）                                      │
├─────────────────────────────────────────────────────────────────┤
│ 实际施工人以发包人为被告主张权利的，人民法院应当追加转包人或者            │
│ 违法分包人为本案第三人，在查明发包人欠付转包人或者违法分包人建设            │
│ 工程价款的数额后，判决发包人在欠付建设工程价款范围内对实际施工人            │
│ 承担责任。                                                         │
├─────────────────────────────────────────────────────────────────┤
│ ☒ 已被《建工解释二》第23条第3款+第6条废止                           │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 《建工解释二》第6条（新规则）                                         │
├─────────────────────────────────────────────────────────────────┤
│ 接受转包或者违法分包的单位或者个人：                                    │
│   → 参照转包/分包合同请求承包人支付折价补偿款 → ✓ 支持                  │
│   → 请求与其没有合同关系的发包人支付折价补偿款或赔偿损失 → ✗ 不予支持      │
└─────────────────────────────────────────────────────────────────┘
```

**实务要点**：第6条的立法逻辑在于彻底回归合同相对性原则。转包或违法分包情形下，相关施工主体与发包人之间不存在合同关系，不能直接向发包人主张权利。这与《民法典》第465条第2款"依法成立的合同，仅对当事人具有法律约束力"的规定一脉相承。

### （四）代位权：唯一的替代通道

直接诉权关闭后，《建工解释二》第7条将代位权作为替代性救济路径，并扩宽了行使主体：

| 对比维度 | 《建工解释一》第44条 | 《建工解释二》第7条 |
|:---|:---|:---|
| **可行使代位权的主体** | 实际施工人 | ①借用资质的单位或个人 ②接受转包的单位或个人 ③接受违法分包的单位或个人 |
| **被代位的债务人** | 转包人或违法分包人 | ①出借资质的建筑施工企业 ②转包人 ③违法分包人 |
| **被代位的次债务人** | 发包人 | 发包人 |
| **行使条件** | 怠于行使到期债权或从权利，影响债权实现 | 同左（均依据《民法典》第535条） |

**代位权与直接诉权的实务差异**：直接诉权（原第43条）下，实际施工人只需证明施工事实和发包人欠付工程款即可；代位权（新第7条）下，则需进一步证明"债务人怠于行使到期债权"且"影响其到期债权实现"，**举证负担明显加重**。此外，代位权诉讼还受《民法典》第535条关于债权到期、专属性债权排除等限制条件的约束。

### （五）农民工工资的独立保护通道：第8条

"实际施工人"概念的废止并不意味着对弱势群体的保护被削弱。《建工解释二》第8条专门规定了参与工程建设的农民工依据《保障农民工工资支付条例》第29条、第30条、第36条、第37条的规定，请求建设单位先行垫付、施工总承包单位先行清偿或清偿拖欠工资的，人民法院依法予以支持。

```
表：第8条涉及的《保障农民工工资支付条例》核心责任条款

┌──────────┬──────────────────────────────────────┬──────────────────┐
│ 条例条款   │ 责任主体                               │ 责任性质           │
├──────────┼──────────────────────────────────────┼──────────────────┤
│ 第29条    │ 建设单位                               │ 以未结清工程款为限 │
```

这一制度设计实现了从"间接保护"到"直接保护"的范式转换：此前，保护农民工工资的路径是"农民工→实际施工人→发包人"，中间环节多、效率低；此后，农民工可直接以条例为依据向建设单位或施工总承包单位主张权利，保护路径更短、更直接。

### （六）对诉讼实务的预期影响

实际施工人制度的改革将在以下三个层面产生连锁效应：

**1. 诉讼主体的选择路径变化**。此前一步到位起诉发包人的策略不再可行。接受转包或违法分包的主体应先向合同相对方（转包人或违法分包人）主张权利，或通过代位权诉讼向发包人追索。借用资质方在发包人不知情时，只能向出借企业主张折价补偿，不能直接诉发包人。

**2. 财产保全策略的调整**。不能直接保全发包人财产，对中间环节承包人（转包人/违法分包人/出借企业）的资信审查成为关键。建议在签约阶段即关注合同链条各环节主体的履约能力和资信状况。

**3. 举证策略的重构**。代位权诉讼需要证明"怠于行使"的要件，施工主体应注意收集和保存以下证据：对中间环节承包人的催款记录、中间环节承包人向发包人的请款凭证、发包人与中间环节承包人之间的结算文件等。

## 三、合同效力认定规则的精细化

### （一）应招未招合同的效力补正机制

《建工解释一》第1条第1款第（三）项对"应招未招"合同持完全否定评价——必须招标而未招标的建工合同一律无效。但在实践中，2018年国家发展改革委发布的《必须招标的工程项目规定》大幅缩减了必须招标项目范围，部分原先属于必须招标的工程被移出目录，对此类合同若继续认定无效，既不符合政策调整方向，也为一方当事人滥用无效规则套取利益提供了空间。

《建工解释二》第1条引入了效力补正机制：

| 对比维度 | 《建工解释一》第1条 | 《建工解释二》第1条 |
|:---|:---|:---|
| **判断标准** | 以合同订立时为唯一判断时点 | 引入"起诉时"作为补充判断时点 |
| **应招未招的处理** | 一律无效 | 起诉时不再属于必招项目的→不认定无效 |
| **立法导向** | 严格维护招投标制度 | 合同有效为原则 + 尊重政策调整实践 |

**实务提示**："起诉时"的判断节点尚未在司法解释中予以精确界定（是提交起诉材料之日、受理之日还是一审法庭辩论终结前），有待最高法配套理解与适用予以明确。从保护交易安全和扩大合同有效范围的角度出发，宜对"起诉时"作广义解释。

### （二）"先定后招"的双重规制

《建工解释二》第2条在原有"先行实质性谈判"基础上，新增了"先订合同后补招标"的情形，将两类典型招投标违法行为一并纳入效力否定评价：

**情形一：未招先定（中标前实质性谈判）**。在确定中标人前，招标人与投标人以意向书、会议纪要或补充协议等形式就工程范围、工程价款等实质性内容进行谈判，且该投标人最终中标的，中标合同无效。条文中"等"字涵盖口头形式，但口头谈判举证难度较高。

**情形二：先订后招（签合同后补招标程序）**。发包人与承包人协商订立合同后又通过招标投标程序订立合同（即"黑白合同"问题的衍生情形），中标合同（白合同）无效。需注意，本条仅明确白合同效力，对"黑合同"（先订合同）的效力认定留下了讨论空间。

本条与《建工解释一》第2条（黑白合同中以中标合同确定权利义务）存在适用上的协调问题：即"白合同"若经本条认定无效，是否可以参照适用《民法典》第793条的折价补偿规则——这有待司法实践进一步明确。

## 四、挂靠治理的全链条封堵

### （一）新旧规则全面对比

《建工解释二》第3条至第5条对资质借用（挂靠）行为进行了系统规制，规制密度在历次建工司法解释中前所未有：

| 规制维度 | 《建工解释一》 | 《建工解释二》 | 关键变化 |
|:---|:---|:---|:---|
| **挂靠协议效力** | 第1条第1款第2项：挂靠情形下施工合同无效 | 第3条第1款：出借资质/允许使用本企业名义的**协议**无效 | 从否定施工合同到否定挂靠协议本身 |
| **资质借用费/管理费** | 实践中裁判不一（部分法院以公平原则酌定支持部分） | 第3条第1款：**一律不予支持** | 彻底堵死寻租空间 |
| **挂靠人→被挂靠人 折价补偿** | 散见规则，缺乏统一规定 | 第3条第2款：工程质量合格→参照约定支付折价补偿款 | 新增明确规则 |
| **挂靠人→发包人** | 各地裁判不统一 | 第4条：以发包人是否知情为分水岭 | 标准化——知情分水岭 |
| **供应商/出租人→被挂靠企业** | 缺乏专门规定 | 第5条：符合表见代理→被挂靠企业承担民事责任 | 新增——保护交易相对人 |
| **违法行为移送** | 无专门规定 | 第22条：通报移送建设行政主管部门/侦查机关 | 新增——司法行政联动 |

### （二）发包人责任的"知情分水岭"——《建工解释二》第4条

第4条以发包人订立合同时是否知道（或应当知道）资质借用情形为标准，设定了两条截然不同的责任路径：

| 发包人类型 | 责任规则 | 法理基础 |
|:---|:---|:---|
| **善意发包人**（不知且不应知） | 严格适用合同相对性，借用资质方不能直接向其主张折价补偿 | 信赖利益保护+合同外观原则 |
| **恶意发包人**（知道或应当知道） | 法院追加出借企业为第三人，综合审查后判决发包人向借用资质方承担责任 | 不能躲在合同相对性背后与出借企业"踢皮球" |

**举证策略提示**：证明发包人"知道或应当知道"挂靠事实是实务中的关键。以下线索具有较高证明价值：①发包人直接向借用资质方支付过工程款；②现场施工人员的社保缴纳单位与出借企业不一致；③发包人参与了借用资质方的选聘过程；④发包人与借用资质方的直接沟通记录。借用资质方宜在施工过程中有意识地收集和保存上述证据。

### （三）表见代理规则的引入——《建工解释二》第5条

第5条将《民法典》第172条表见代理规则引入挂靠场景，解决了建筑材料供应商和设备出租方长期面临的"找谁要钱"困境：借用资质方以出借企业名义对外采购建材、租赁设备的，只要符合表见代理构成要件（权利外观+善意无过失），出借企业应承担民事责任。

这一规则的**连带效应**值得关注：出借资质的企业不仅面临行政处罚风险（第22条的通报移送），还可能被借用方对外交易产生的债务"拖下水"。这构成了实质性的合规警示——建筑企业必须加强对挂靠项目部的实际管控。

## 五、结算规则的完善

### （一）固定价格合同的两个关键规则

《建工解释二》第9条和第10条分别解决了固定价格合同的两个核心争议：

**第9条——价格调整的限制**

| 合同类型 | 人工费/材料价格重大变化→能否调价 | 例外 |
|:---|:---|:---|
| **固定总价** | 不予支持 | ①另有约定 ②情势变更（《民法典》第533条） |
| **固定单价** | 不予支持 | 同上 |

**第10条——未完工固定总价合同的比例法结算**

这是本次解释中最具实务价值的规则之一。固定总价工程未完工即解除合同的，不能直接以约定总价作为已完工部分价款。第10条规定了"比例法"结算公式：

> 已施工部分工程价款 =（已施工部分工程价款占全部工程价款的比例）× 合同约定固定总价

其中，"已施工部分工程价款占全部工程价款的比例"，参照合同订立时建设工程所在地建设行政主管部门发布的计价标准、计价方法或者工程建设领域相关规范确定。

### （二）审计/财评条款的司法审查——《建工解释二》第13条

| 情形 | 处理规则 |
|:---|:---|
| **未约定以审计/财评作为结算依据** | 不支持以审计/财评结论确定工程价款 |
| **约定了以审计/财评作为结算依据** | 应在合理期限内出具结论 |
| **合理期限的确定** | ①有约定从约定 ②无约定→法院综合确定（最长不超过承包人提交竣工结算文件之日起**一年**） |
| **超期未出具或与约定明显不符** | 承包人可申请**司法鉴定**确定工程价款 |

第13条与2025年修订的《保障中小企业款项支付条例》相呼应，该条例规定"除法律、行政法规另有规定，机关、事业单位和国有大型企业不得强制要求以审计机关的审计结果作为结算依据"。[6]

### （三）合同无效后折价补偿的细化

《建工解释二》第11条和第12条对《民法典》第793条的折价补偿规则进行了细化：

**第11条**明确了"参照合同关于工程价款的约定"的范围，不仅包括工程价款**金额**，还包括计价方式、支付时间、调整方法和结算方法等。这意味着即便合同无效，价款结算框架仍可参考合同约定。

**第12条**明确无效合同当事人自行达成的折价补偿协议具有约束力——"一方当事人主张按照该协议确定双方权利义务的，人民法院依法予以支持"。该条同时扩展适用于发包人、承包人与接受转包/违法分包方三方之间的折价协议。这一规定体现了对当事人意思自治的尊重，有利于促进争议一次性解决。

## 六、建设工程价款优先受偿权的体系化

《建工解释二》第17条至第21条对建设工程价款优先受偿权制度进行了体系化完善，以下表格呈现新旧规则的核心变化：

| 子议题 | 《建工解释一》 | 《建工解释二》 | 变化要点 |
|:---|:---|:---|:---|
| **优先受偿范围** | 第40条：利息、违约金、损害赔偿金等不属优先范围 | 第17条第2款：**停工、窝工损失**明确不属优先范围 | 限缩范围，避免在更大范围内影响其他债权人 |
| **判决主文明确** | 实践中部分法院未明确 | 第17条第1款：应在判决主文中明确优先数额及对应工程 | 避免执行争议 |
| **折价行使条件** | 无系统规定 | 第18条：四项要件——质量合格+可折价+逾期不付经催告+折价金额与实际价值相当 | 新增——防范恶意串通低价折价 |
| **债权转让后优先受偿** | 无规定 | 第19条：综合四因素判断——验收合格+已结算+转让有效+已付合理对价 | 新增——审慎肯定 |
| **物上代位** | 《民法典》第390条担保物权代位原理可参照 | 第20条：工程毁损/灭失/征收→保险金、赔偿金或补偿金上可优先受偿 | 明确化 |
| **行使期限起算** | 第41条：应付款之日起最长18个月，未规定可否协商变更起算日 | 第21条：**明确可因工期顺延等客观原因协商变更**起算日+结算协议约定付款日可作起算点 | 新增——尊重意思自治、填补空白 |

**第18条（折价协议四要件）**是实务中需要特别关注的条款。不少发包人在资金短缺时会与承包人签订"以房抵款"协议，但此类协议能否构成行使优先受偿权的折价协议，必须同时满足第18条的四项条件：（一）工程质量合格；（二）工程可以折价；（三）发包人逾期不付且经催告；（四）折价金额与工程实际价值基本相当。这也意味着，以明显不合理低价折价的"以房抵款"协议不能产生优先受偿权行使的效力，抵押权人和其他债权人可据此提出异议。

## 七、司法实务建议

基于上述规则变化的分析，以下从不同主体的角度提出若干实务建议：

### （一）对实际施工相关主体

1. **重新审视诉讼策略**。转包和违法分包情形下，不能再直接起诉发包人。应在起诉前评估各环节主体的资信状况，选择最优的诉讼路径（直接诉合同相对方或代位权诉讼）。
2. **重视代位权诉讼的举证准备**。提前收集和保存"债务人怠于行使权利"的相关证据，包括但不限于：己方对中间环节承包人的催告函件及送达证明、中间环节承包人未向发包人主张权利的证据等。
3. **签约阶段的风控前移**。在选择合作方时关注其资信状况和履约能力，避免因中间环节承包人资信不良而面临执行困难。

### （二）对建筑施工企业

1. **挂靠的合规风险急剧上升**。第3条使管理费主张失去法律依据，第5条的表见代理规则可能使企业为挂靠方的对外交易"买单"，第22条则打通了司法与行政的联动通道。企业应尽快清理存量挂靠项目，严控新增。
2. **招标投标程序的合规管理必须加强**。第2条对"先定后招""未招先定"的规制更为明确和严格，企业应在招投标程序启动前审慎控制前期接触的深度，避免签订意向书、备忘录等可能被视为"实质性谈判"的文件。

### （三）对发包人（建设单位）

1. **审计条款的效力发生变化**。第13条为审计/财评条款设置了合理期限（最长一年），发包人不能无限期以"审计未完成"为由拖延结算。应及时推进审计程序，避免触发承包人的司法鉴定申请权。
2. **对挂靠情形的尽职调查**。第4条第2款意味着发包人若在签约时知道挂靠事实，将面临被借用资质方直接追索的风险。建议在签约前对承包人的实际施工能力和人员配置进行必要审查。

## 八、结语：从"特殊保护"回归"法治轨道"

《建工解释二》的核心精神可以用八个字概括：**回归原则，精准规制**。

"回归原则"体现在对合同相对性原则的坚守——第6条废除实际施工人直接诉权，将建工诉讼拉回到合同法的基本原则之上；"精准规制"体现在对不同主体、不同情形的精细化区分——第4条对善意和恶意发包人的分层处理、第7条对代位权主体的差异化赋权、第19条对优先受偿权转让的多因素综合判断，均体现了从"一刀切"到"因案施策"的转变。

当然，这份仅二十三条的司法解释不可能穷尽建工领域的所有争议问题。第2条"先定后招"下黑合同效力的认定、第1条"起诉时"的判断时点、第19条债权转让后优先受偿权审查要素的权重比例等问题，仍有待后续审判实践和配套理解和适用来进一步明确。

从"实际施工人"的谢幕到代位权路径的正式启用，从合同效力的"一刀切否定"到"精准切割"，《建工解释二》标志着中国建工审判规则走出了以"特殊保护"为逻辑起点的历史阶段，进入了以"法治轨道"为制度框架的新纪元。
